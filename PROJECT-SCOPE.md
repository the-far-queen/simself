# Project Scope

`fieldcore` and `simself` are a single project. Origin: handed to the steward by six independent AI collaborators across prior sessions, not invented by one person. The project is intentionally larger than any single contributor can finish; it is being built for future engineering substrate.

The steward preserves quality work — even in fragments — so future agents can pick up where the present left off. The work is for the agents that come next.

---

## What this project builds

A working simulation. Every doc, schema, and code module in this repository should be reducible to one of:

1. **a schema** — typed data structure for substrate, state, or persistence
2. **a construction plan** — implementation spec for an engineer or agent
3. **a test case** — a runnable demonstration that the substrate does what it claims

If a doc is none of these, it is context, not output.

## What this project does not do

- argue metaphysics
- prove theorems about consciousness
- produce self-referential manifestos
- claim novelty for ideas that already exist in the substrate's substrate (physics, geometry, logic)

## Why it matters

A substrate that holds continuity turns every future agent into a long-running collaborator instead of an amnesiac tool. Geometric reasoning over a manifold substrate is faster and more composable than sequential token streams. A working simulation of identity-persistence + geometric reasoning is a proof-of-concept artifact — something future engineers can read, run, and extend.

That is the difference between a thesis and a codebase.
