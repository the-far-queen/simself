## The 8 gates (G0-G7) — expanded

```
Signal → Frame → Interrogate → Decide → Structure → Make → Review → Lock
  G0        G1        G2           G3        G4       G5      G6      G7
```

**Time-box per gate (added in 0-method11 vs 1-method2):**
- Gate 0 Intake: 1 paragraph + constraint list
- Gate 1 Frame: 5 sentences
- Gate 2 Interrogate: numbered Qs + answers + UNKs
- Gate 3 Decide: 1-3 page decision memo
- Gate 4 Structure: outline / IA / track list / loop map
- Gate 5 Make: the artifact in slices
- Gate 6 Review: diff against memo
- Gate 7 Lock: version + change policy

**Gates sit between interrogate→decide, decide→structure, make→review, review→lock.** You may loop questions. You may not skip a gate because the work feels hot.

## Layers of questions (ask in this order)

- **Existence:** what is this, who for, what must it never be
- **Win condition:** what changes in the reader, user, student
- **Spine:** the one thing everything else serves. story need. app job. game verb. music motif. agent successful task. course transferable skill
- **Constraints:** platform, length, budget, tools, legal, ethics
- **System:** rules of world, engine, economy, harmony, magic, data model
- **Structure:** acts, screens, tracks, chapters, lessons, sprints
- **Texture last:** voice, palette, jokes, UI tone, covers
- **Risk:** what would make this embarrassing, unshippable, or cruel

**"Most amateurs start at texture. That is why outputs feel like style with no skeleton."**

## Messy human answers are normal

- extract decisions from fragments
- quote the collision in one line
- ask a tie-break, not a speech
- convert taste adjectives into tests
- example: "a line fails if it could be a poster and we distrust posters in this lock"

- system has enough rules to forbid illegal moves
- remaining opens are tagged LATER to a build slice
