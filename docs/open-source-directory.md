8. LICENSE COMPATIBILITY CHECKLIST
Government/Military Code
	•	Usually: Public Domain (CC0), Apache 2.0, MIT
	•	Watch for: "Government Purpose Rights", export controls
	•	Check: LICENSE file, NOTICE files
University Code
	•	Common: BSD variants, MIT, Apache 2.0
	•	Research code: Often requires citation
	•	Check for: "Non-commercial use only" clauses
Corporate Research
	•	Usually: Apache 2.0, MIT
	•	Some: GPL (avoid for commercial)
	•	Check: Patent clauses in Apache 2.0
Key Licenses for Commercial Use
	1.	MIT - Most permissive
	2.	Apache 2.0 - Patent protection
	3.	BSD-3-Clause - No endorsement
	4.	CC0 - Public domain equivalent
	5.	MPL 2.0 - File-level copyleft
Avoid (for commercial products)
	•	GPL v3 - Requires source release
	•	AGPL - Network use triggers copyleft
	•	Non-commercial licenses
