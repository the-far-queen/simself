## Caveats — applied to ALL papers in this folder

Same discipline rules as fieldcore/docs/research-papers/README.md. Repeating for emphasis:

### 1. Isomorphism vs Identity

> "X is structurally equivalent to Y on manifold M" is defensible, citable, publishable.
> "X IS Y" is mysticism, will get rejected by reviewers.

**Every paper includes an explicit "is not" section listing what the substrate is NOT.**

### 2. No numerology

- No atomic-number symbolism, no sacred geometry, no φ mysticism.
- **Simself-specific:** no Schumann/432/963 Hz numerics. These are isolated hypotheses in `frequency.py`. Constitutional core stays clean.

### 3. No consciousness claims

- SimSelf is a mathematical model of substrate identity, not a claim about machine consciousness.
- 20 axes + harmonic-only update = mathematical structure, not subjective experience.
- Gödel/Lovelace: the constitutional growth paradigm is a model. The 7-stage embryogenesis is a model. Models are not consciousness.

### 4. No chip-fab speculation in academic papers

- Future chip design (H₃O₂ sheets, Bi₂Se₃ layers) is **project doc**, not paper claim.
- Papers describe computational results on existing Python substrate.

### 5. Failure modes are publishable

- `test_frequency_layer.py` 7/7 pass — successes.
- Atlas exam 4/5 — HONEST LIMITATION.
- Routing 2/5 pre-existing flakiness — case study.
