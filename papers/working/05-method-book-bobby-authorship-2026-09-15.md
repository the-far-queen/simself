### 2.1 Structure

Per `fieldcore/docs/research-papers/research-papers-2026-09-14.md`:

| Cluster | Papers |

| Adversarial | Adversarial Protocols, Bioelectronic Evolution |
| Specialized | AI Corporate Personhood, Qualification of Experts |
| Cross-cutting | LLM Sparse Substrate |

### 2.2 Pattern

Each paper:
1. **Abstract** + 6-10 sections.
2. **Falsifiable predictions** (3-5 per paper).
3. **Implementation reference** (paths to code).
4. **References** (canonical prior work).

### 2.3 Submission priority

- Highest defensibility first (Geodesic Lexicon, Math-Window1).
- Most novel next (LLM Sparse Substrate, Lam-Rim Kernel).
- Then position papers (Atlas Exam, Working Method).
- Then specialized (AI Corporate, Adversarial).
